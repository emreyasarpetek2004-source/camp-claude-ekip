# UKCAMP Görsel Tasarım Sistemi (@camp2uk)

> Kaynak: 495 @camp2uk postu + kapak görsel incelemesi (Apify, Tem 2026). Amaç: statik post üretim otomasyonunun **UKCAMP görsel kimliğini birebir korumasını** sağlamak. Tasarımcı brief'lerinin görsel referans omurgası.
> ⚠️ UKCAMP kimliği AUSCAMP'ten **bağımsızdır** — yeşil/altın YOK; Union Jack (mavi + kırmızı + beyaz) kullanılır.

---

## 1. RENK PALETİ (Union Jack)
| Renk | Kullanım | Yaklaşık |
|------|----------|----------|
| **Royal / Lacivert Mavi** | Baskın zemin, gradyan, "CAMP" logosu, pill başlık | ~#1E4FA0 → #10357A |
| **Kırmızı** | Pill başlık (dönüşümlü), kurdele/şerit, alt CTA barı, vurgu | ~#E01B2E |
| **Beyaz** | Metin, logo kutusu, başlık kutuları, kontrast | #FFFFFF |
| **Açık mavi** | Gradyan geçiş, ikincil zemin | ~#2E80C8 |

Co-brand: **MEDCAMP English** (OET) — kırmızı+yeşil logosu yan yana kullanılabilir.

## 2. LOGO
- **"UK CAMP"** — `UK` Union Jack bayrak dokusuyla (kırmızı/mavi/beyaz), `CAMP` lacivert bold; **beyaz yuvarlatılmış dikdörtgen** kutu içinde.
- Konum: **üst-orta** (içerik slaytları) veya **üst-sol / alt-sol** (kapaklar).
- Co-brand gerektiğinde yanında MEDCAMP English logosu.

## 3. SABİT GÖRSEL ÖĞELER
- 🇬🇧 **Union Jack bayrağı:** kapak slaytının köşesi veya yanı (dalgalı bayrak görseli sık).
- **Doktor cutout:** beyaz önlük + stetoskoplu portre, mavi zemin/gradyan üstünde (sol veya köşe).
- **Pill / konuşma-balonu başlık kutuları:** yuvarlatılmış, **kırmızı & mavi dönüşümlü**.
- **Kırmızı kurdele/şerit:** "Sorunuzu İnceliyoruz!" gibi aksiyon etiketleri.
- **Alt kırmızı CTA barı:** 🌐 ukcamp.com.tr · 📲 +90 552 253 0 337 · 📩 info@ukcamp.com.tr.

## 4. TİPOGRAFİ
- Başlık: **kalın sans-serif**, BÜYÜK HARF veya Title Case.
- Kontrast: **mavi zemin → beyaz metin**, **beyaz kutu → lacivert metin**.
- Vurgu: anahtar kelimeye **kırmızı veya beyaz pill** arka plan; tırnak içi büyük soru (mit-yıkma).

## 5. MADDE İŞARETİ SİSTEMİ
| İşaret | Bağlam |
|--------|--------|
| ✅ | Fayda / özellik listeleri |
| • (beyaz) | Genel maddeler (mavi zemin) |
| 📌 ✔ | Bilgi / süreç maddeleri |
| Emoji-başlı (📚🏥🩺🤝) | Hizmet / süreç içerikleri |

## 6. SLAYT ANATOMİSİ (carousel standardı — ort 5.3 slayt)
1. **KAPAK:** logo + Union Jack bayrak + büyük başlık (pill kutularında, vurgulu kelimeler) + doktor foto/cutout + opsiyonel seri no.
2. **İÇERİK:** logo (üst) + alt başlık + madde gövde + görsel.
3. **KAPANIŞ / CTA:** alt kırmızı bar veya mavi zemin + "Bizimle iletişime geçin / Takipte kalın" + sabit CTA bloğu + logo.

## 7. FOTOĞRAF STİLİ
- **Mentör:** cutout portre, mavi zemin/gradyan üstünde.
- **Stok:** klinik/hastane, beyaz önlüklü doktorlar, Londra/İngiltere görselleri (Big Ben, NHS ortamı).
- **Bayrak:** 🇬🇧 dalgalı Union Jack tekrarlayan marka öğesi.

## 8. ŞABLON TAKSONOMİSİ (10 tip) — otomasyonun çıktı tipleri
> Yapı AUSCAMP T1–T10 ile paralel; **renk = Union Jack**, içerik = UK.

### T1 — Webinar Duyurusu
Bayrak köşe + logo + **audience pill** (`HERKESE AÇIK, ÜCRETSİZ!` / `UKCAMP ÖĞRENCİLERİNE ÖZEL`) + büyük başlık + **mentör cutout** + **takvim kutusu** (📅 tarih + ⏰ saat) + mentör adı (pill) + rol. Zoom ise 💻.

### T2 — Aylık Webinar Takvimi
Kapak: büyük ay + "Webinarları" + webinar listesi (mini mentör fotoğrafı + tarih + başlık + audience etiketi) + footer CTA barı. Ardından her webinar için T1 tarzı slayt.

### T3 — Bilgilendirme (Süreç / Sistem / NHS / Yaşam)
Mavi zemin/gradyan. Kapak: bayrak + başlık + foto. İçerik: başlık + ✅/• madde + görsel. Süreç serileri (PLAB adımları, GMC evrakları) madde madde. Son slayt CTA barı. Veri alt-tipi: bar chart (ör. branş-branş NHS doktor sayıları).

### T4 — Mit-Yıkma ("… yapabilir miyim?")
Kapak: mavi gradyan + doktor cutout + tırnak içi büyük beyaz soru + 🇬🇧 bayrak + **kırmızı kurdele "Sorunuzu İnceliyoruz!"**. İçerik: soru → net cevap + ✅ maddeler.

### T5 — Başarı / GMC-NHS ("Tebrik")
Slayt 1: kutlama başlığı (PLAB 2 geçti / GMC tamamlandı / NHS'te işe başladı) + konfeti + varsa belge/danışan mesajı. Slayt 2: süreç timeline. Son: CTA barı.

### T6 — Mentör Tanıtımı (en yüksek etkileşim)
Slayt 1: mavi + logo + büyük isim (beyaz) + **"UKCAMP'te!"** banner + mentör cutout + bayrak. Slayt 2: biyografi (NHS'te konum + branş). Slayt 3: CTA. *(Video versiyonu tercih edilir — en çok beğeni video mentör tanıtımında.)*

### T7 — Ekip Tanıtımı
Kapak: "UKCAMP Ekibini Tanıyalım" + grup. Her mentöre 1 slayt: 📍 NHS şehri/hastane etiketi, foto, isim + rol (Registrar/Consultant/branş) + kısa bio.

### T8 — Hizmet / İşbirliği
Kapak: foto + başlık. İçerik: "Size Neler Sunuyoruz?" (PLAB / OET / GMC / NHS danışmanlık) + hizmet listesi. Co-brand: OET → MEDCAMP English. Son CTA.

### T9 — Canlı Yayın (Instagram Live)
T1 benzeri ama "**Canlı Yayın!**" pill + `📷 LIVE @camp2uk` + "Kaçırmamak için takip edin". Soru slaytı: → maddelerle gündem.

### T10 — Kampanya / Dönemsel (yüksek performans)
**Dramatik** kampanya kapağı (foto + büyük kırmızı/beyaz pill) — "2 Haftalık ÜCRETSİZ Deneme", "Yeni Yıl Fırsatı" — süre/tarih + fayda listesi + güçlü CTA.

## 9. OTOMASYON İÇİN GÖRSEL STANDART ÇIKARIMI
Tasarımcı brief'i her zaman belirtmeli:
1. **Şablon tipi** (T1–T10) — mevcut tasarım yeniden kullanılır.
2. **Slayt sayısı ve rolü** (kapak / içerik / CTA).
3. **Stil:** foto-zemin + pill (Stil A) / mavi gradyan + cutout (Stil B).
4. **Sabitler:** logo, 🇬🇧 bayrak köşesi, CTA barı (web + telefon + e-posta).
5. **Segment görsel ipucu:** PLAB 📚, NHS 🏥, mentör cutout, GMC 📄 belge, yaşam Londra/şehir.
6. **Vurgu kelimeleri:** kırmızı/beyaz pill ile işaretlenecek anahtar kelimeler.
7. **Ölçü:** 1080×1350 (4:5 dikey) — **sabit standarttır, brief'e YAZILMAZ.** `ukcamp-orkestra-sefi` ve `ukcamp-asana-task` "piksel ölçüsü yazma" diyor; ölçü tasarımcı tarafından bilinir, her brief'te tekrarlanmaz. Story: 1080×1920.
